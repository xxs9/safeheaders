# SafeHeaders

Навчальний Python CLI, який перевіряє базові HTTP-заголовки безпеки однієї вебсторінки та пояснює результати зрозумілою мовою.

## Для кого

Для початківців у Python і кібербезпеці, які хочуть побачити, як браузерні захисні заголовки впливають на безпеку сайту.

## Що перевіряє

- Чи відкривається адреса через HTTPS.
- Чи присутні `Strict-Transport-Security`, `Content-Security-Policy`, `X-Content-Type-Options`, `Referrer-Policy` та `Permissions-Policy`.
- Чи не розкривають `Server` і `X-Powered-By` зайві відомості про технології.
- Підсумкові зауваження з поясненнями та посиланнями на документацію.

Звіт — це навчальна підказка, а не повний аудит чи оцінка захищеності. Наявність заголовка сама по собі не доводить, що його значення налаштоване правильно.

## Запуск

Потрібен Python 3.10 або новіший. Зовнішні пакети не потрібні.

```bash
python safeheaders.py https://example.com
```

Щоб побачити JSON для подальшої обробки:

```bash
python safeheaders.py https://example.com --json
```

## Етичне використання

Перевіряй лише сайт, яким володієш або на перевірку якого маєш дозвіл. Програма робить один звичайний HTTP GET запит до вказаної сторінки, не обходить сайт і не намагається використати вразливості. Перевір політику сайту та переконайся, що така перевірка дозволена.

## Приклад звіту

```text
SafeHeaders — базова перевірка заголовків
Адреса: https://example.com/
HTTPS: так

Підсумок: 3 з 5 захисних заголовків знайдено

[OK] Strict-Transport-Security — браузеру наказано використовувати HTTPS.
[УВАГА] Content-Security-Policy — не знайдено; політика CSP допомагає обмежити джерела вмісту сторінки.
```
